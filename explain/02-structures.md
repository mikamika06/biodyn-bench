## Чому саме форми, а не просто «звʼязок»

У даних ти бачиш, що два гени коливаються в такт. Це називають **кореляцією**. Але кореляція не каже, **чому** так вийшло.

Для трьох змінних існує **вичерпний список** способів їх сполучити стрілками без циклів. Це не чиясь думка, а математичний факт із теорії причинності.

Розберу спершу чотири базові, потім чотири наші додаткові.

---

# Базові чотири

## 1. Пряме ребро

```
X ──▶ Y
```

`X` справді керує `Y`. Вимкнеш `X` — `Y` зміниться.

**Побутовий приклад:** вимикач і лампа. Клацнув — світло згасло.

**У даних:** сильна кореляція, і вона «справжня».

**Наш код:** усередині кожної панелі є пари типу `D` — від слова `direct`.

```python
x = p.new()                              # незалежний ген
y = k * p.sign() * p.f(x) + p.eps()      # y залежить від x
p.pairs["D"].append((p.add(x), p.add(y)))
```

Читається так: беремо випадковий ген `x`, робимо `y` пропорційним до нього плюс шум. `k` — сила звʼязку, `p.eps()` — шум.

---

## 2. Спільна причина, вона ж конфаундер

```
    A
   ╱ ╲
  ▼   ▼
  B   C
```

`B` і `C` між собою **не повʼязані ніяк**. Обидва слухаються `A`.

Вимкнеш `B` — `C` **не зміниться**. Звʼязку немає, а кореляція є.

**Побутовий приклад:** влітку люди їдять морозиво, і влітку люди тонуть. Кореляція між продажем морозива й утопленнями сильна. Морозиво нікого не топить — обидва є наслідками спеки.

**Слово «конфаундер»** означає «те, що плутає». Це змінна, яка створює видимість звʼязку між двома іншими.

**Чому це головна пастка біології:** значна частина «відкритих регуляцій» такі. Два гени слухаються третього, і хтось малює між ними стрілку.

**Наш код**, `src/sim/grid.py`:

```python
def s_confounder(p, k, hide):
    a = p.new()                                    # корінь
    b = 2.0 * p.sign() * p.f(a) + p.eps()          # A керує B
    c = 3.0 * p.sign() * p.f(a) + p.eps()          # A керує C
    p.add(a, hidden=hide)                          # корінь можна СХОВАТИ
    p.pairs["S"].append((p.add(b), p.add(c)))      # міряємо пару (B,C)
```

`hidden=hide` — прапорець, який дозволяє **викинути корінь із даних**. Це моделює реальність: у справжньому експерименті міряють дві тисячі генів із двадцяти тисяч, і потрібний регулятор часто просто не потрапляє в панель.

Це дає **дві різні задачі з однієї структури**:

```
корінь видимий      задача РОЗВʼЯЗНА    є на що обумовитись
корінь прихований   задача НЕМОЖЛИВА    обумовлюватись нема на що
```

## 3. Ланцюг

```
A ──▶ B ──▶ C
```

`A` впливає на `C` **насправді**, але через посередника. Прямого ребра між ними немає.

Вимкнеш `A` — `C` **зміниться**. Тобто вплив є. Але якщо намалюєш стрілку `A → C`, ти збрешеш про механізм: між ними стоїть `B`.

**Побутовий приклад:** дощ → мокра дорога → аварії. Дощ не спричиняє аварій напряму. Якби дорогу висушили, дощ перестав би впливати.

**Чому це критично для мережі:** мережа складається з **прямих** ребер. Метод, що малює стрілку щоразу, коли вплив є хоч якийсь, намалює не мережу, а її «транзитивне замикання» — ліс стрілок замість ланцюжка.

**Наш код:**

```python
def s_chain(p, k, hide):
    a = p.new()
    b = 2.0 * p.sign() * p.f(a) + p.eps()
    c = 2.0 * p.sign() * p.f(b) + p.eps()
    ia = p.add(a)
    ib = p.add(b, hidden=hide)                     # посередника можна сховати
    p.pairs["S"].append((ia, p.add(c)))            # міряємо пару (A,C)
```

Тут ховається **посередник**. Коли `B` видимий, метод може обумовитись на ньому й побачити, що прямого звʼязку немає. Коли `B` прихований — не може.

## 4. Колайдер, він же спільний наслідок

```
  A     C
   ╲   ╱
    ▼ ▼
     B
```

`A` і `C` **незалежні повністю**. Кожен окремо впливає на `B`.

У сирих даних вони **не корелюють**. Усе чесно.

Пастка вмикається, коли метод починає **обумовлюватись**, тобто враховувати значення `B`.

### Числова інтуїція

Хай `B = A + C`. Зафіксували `B = 10`.

```
дізнались A = 3    отже C = 7
дізнались A = 8    отже C = 2
```

**До** фіксації `B` знання про `A` не давало нічого про `C`.
**Після** фіксації дає все, причому зі знаком мінус.

Обумовлення на спільному наслідку **створює залежність із нічого**.

### Побутовий приклад

У виш беруть або за оцінками, або за спортивними досягненнями. Серед **вступників** оцінки й спорт корелюють **відʼємно**: хто слабший у навчанні, той пройшов завдяки спорту.

Серед **усіх абітурієнтів** такого звʼязку немає. Він виник від **відбору** — тобто від обумовлення на факті вступу.

### Наш код

```python
def s_collider(p, k, hide):
    a, c = p.new(), p.new()                        # НЕЗАЛЕЖНІ
    b = p.sign() * p.f(a) + p.sign() * p.f(c) + p.eps()
    ia = p.add(a)
    p.add(b, hidden=hide)
    p.pairs["S"].append((ia, p.add(c)))            # міряємо (A,C)
```

### Чим цей стовпець особливий

У всіх інших правильна відповідь — «якомога вище». Тут — **рівно `0.5`**, тобто метод не має бачити різниці.

Одиниця тут означає, що метод **вигадав** ребро.

Це важливо для розмови: наявні бенчмарки такого стовпця не мають узагалі, бо вони будуються на **списках відомих ребер**, а список не містить неребер.

# Наші додаткові чотири

Базові чотири вичерпують три змінні. Але реальна регуляція складніша, і ми додали ще чотири форми.

## 5. Feed-forward loop, петля прямого проходження

```
A ──▶ B
│      │
└──▶ C ◀┘
```

Тобто `A → B`, `A → C`, і ще `B → C`.

**Що особливого:** між `A` і `C` ребро **є**, але паралельно йде ще й обхідний шлях через `B`. Питання: чи знайде метод пряме ребро, коли поруч є обхід.

**Побутово:** начальник дає завдання і напряму тобі, і твоєму керівнику, який теж передає його тобі. Вплив подвійний.

**Чому цікаво:** якщо два шляхи мають **протилежні знаки**, вони гасять один одного. Наші виміри це показали — про це у файлі `08`.

```python
def s_ffl(p, k, hide):
    a = p.new()
    b = 2.0 * p.sign() * p.f(a) + p.eps()
    c = 1.2 * p.sign() * p.f(a) + 1.5 * p.sign() * p.f(b) + p.eps()
```

Дивись на `c`: він залежить і від `a` **напряму**, і від `b`, який сам залежить від `a`.

## 6. Зворотний звʼязок

```
A ⇄ B
```

`A` впливає на `B`, і `B` впливає на `A`.

**Побутово:** термостат і температура. Холодно → вмикається обігрів → тепліє → обігрів вимикається.

**Чому складно:** таку залежність не можна порахувати за один прохід. Треба **ітерувати** до стаціонарного стану:

```python
def s_feedback(p, k, hide, iters=60, w=0.6):
    a, b = p.new(), p.new()
    ea, eb = p.eps(), p.eps()
    for _ in range(iters):
        a_new = w * sa * p.f(b) + ea
        b = w * sb * p.f(a) + eb
        a = a_new
```

Шістдесят кроків, доки система не заспокоїться. Коефіцієнт `w = 0.6` менший за одиницю, інакше значення розлетілись би в нескінченність.

**Питання стовпця:** чи побачить метод, що звʼязок взаємний. Напрямку тут немає в принципі — обидва напрямки істинні.

## 7. Два приховані батьки

```
H1 ──┬──▶ B
     └──▶ C
H2 ──┬──▶ B
     └──▶ C
```

Те саме, що конфаундер, але конфаундерів **два**, і обидва приховані.

**Побутово:** двоє людей незалежно рекомендують той самий фільм двом твоїм друзям. Друзі подивились той самий фільм — здається, вони змовились.

**Навіщо додали:** перевірити, чи витримають методи ускладнення. І виявилось, що **не всі**. `ARACNe` ламається — про це у файлі `05`.

```python
def s_two_hidden(p, k, hide):
    h1, h2 = p.new(), p.new()
    b = 1.5 * p.sign() * p.f(h1) + 1.5 * p.sign() * p.f(h2) + p.eps()
    c = 1.5 * p.sign() * p.f(h1) + 1.5 * p.sign() * p.f(h2) + p.eps()
    p.add(h1, hidden=hide)
    p.add(h2, hidden=hide)
```

## 8. Комбінаторна логіка: AND і OR

**AND — синергія.**

```
C вмикається, лише коли увімкнені ОБИДВА: A і B
```

**Побутово:** двері відчиняються, лише якщо два ключі повернути одночасно. Кожен ключ окремо не робить нічого.

**Чому це ламає методи:** кореляція між `A` і `C` **майже нульова**. Бо коли `B` вимкнений, зміна `A` нічого не дає. Половину часу вплив є, половину немає — у середньому виходить нуль.

```python
def s_and(p, k, hide):
    a, b = p.new(), p.new()
    c = 2.5 * p.sign() * p.f(a) * p.f(b) + p.eps()   # ДОБУТОК, не сума
```

Ключове — **множення**, а не додавання. У добутку внесок `a` залежить від значення `b`.

**OR — надлишковість.**

```
C вмикається, якщо увімкнений ХОЧА Б ОДИН: A або B
```

**Побутово:** дві лампи в кімнаті. Вимкнеш одну — світло лишається.

**Чому цікаво:** протилежна проблема. Вимкнення одного батька майже нічого не змінює, бо другий підстраховує.

```python
def s_or(p, k, hide):
    soft = np.maximum(p.f(a), p.f(b))                # максимум = мʼякий OR
    c = 2.0 * p.sign() * soft + p.eps()
```

# Головна таблиця

Ось чому все це має значення.

```
структура        методи, що дивляться   методи, що
                 лише на пару           обумовлюються
пряме ребро           бачать                бачать
конфаундер         ПОМИЛЯЮТЬСЯ              бачать
ланцюг             ПОМИЛЯЮТЬСЯ              бачать
колайдер              праві             ПОМИЛЯЮТЬСЯ
```

**Обумовлення — це і сила, і пастка одночасно.** Воно розвʼязує конфаундер і ланцюг. Воно ж створює колайдерне ребро з нічого.

Немає методу, який виграє скрізь. І це не інженерна недоробка, яку можна залатати — це **межа того, що взагалі виводиться зі спостережень**.

## Дві структури, статистично нерозрізненні

Окремо варто знати цей факт.

```
ланцюг     A → B → C
розвилка   A ← B → C
```

Вони дають **однакові дані**. У обох `A` і `C` корелюють, і в обох звʼязок зникає при обумовленні на `B`.

Жоден метод не відрізнить їх зі спостережень. Це називають **класом еквівалентності Маркова**, і це доведена межа, а не слабкість алгоритмів.

Колайдер із цієї трійці **випадає** — у нього протилежний відбиток. Тому він єдиний, який зі спостережень **можна** розпізнати.
