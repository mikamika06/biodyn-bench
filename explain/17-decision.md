# 17. Який метод коли: зведення всіх вимірів

[← назад](00-start-here.md)

Це підсумок усього, що стенд виміряв, у вигляді, придатному для рішення.

Правило скрізь одне: **число читається проти підлоги свого режиму**, не проти `0.5`.

## Що з цього випливає, коротко

### Немає методу, який виграє скрізь

І це не інженерна недоробка. Кожен рядок, де метод провалюється, має **причину, що випливає з його побудови**:

```
кореляція, MI       дивляться лише на пару → сліпі до конфаундера й ланцюга
часткова кореляція  обумовлюється → потрапляє в моралізацію на колайдері
ARACNe              правило трикутника на ОДНОГО посередника → падає на двох
                    маргінальна MI в основі → падає від зсувів типів клітин
glasso              L1 гасить слабкі ребра → менша моралізація, менша точність
LiNGAM              парна асиметрія → тоне в непрямих шляхах у мережі
```

### Часткова кореляція має відʼємний чистий бал

```
метод              розрізняє   вигадує   чистий
ARACNe               0.461     0.076     0.385
LiNGAM               0.324     0.047     0.277
взаємна інф.         0.190     0.032     0.159
кореляція            0.006     0.010    -0.004
часткова кор.        0.356     0.515    -0.159
```

Її провал на колайдері (`0.515`) більший за виграш на решті (`0.356`).

**Але** у звʼязному графі вона єдина, що витримує суміш типів клітин, де ARACNe розсипається. Тобто «найкращий метод» залежить від того, який режим у тебе насправді.

### Три речі, які не лагодяться методом

```
1  ключовий вузол не в панелі      усі методи на підлозі, це межа даних
2  p/n близько 1                   усі на підлозі, і glasso не рятує
3  високий CV рівнів генів         усі на підлозі, глибина не рятує
```

Це **межі даних до методу**. Найкращий алгоритм не витягне того, чого немає.

### Дві речі, які лагодяться не методом, а планом експерименту

```
кілька типів клітин / середовищ    ДОПОМАГАЄ обумовленню (0.61 → 0.87)
негаусів шум                       робить напрямок ідентифіковним
```

Перше — під контролем експериментатора. Друге — властивість біології, яку ніхто не міряв.

## Практичний порядок дій

```
1  порахуй CV середніх рівнів генів своєї панелі      один рядок коду
   CV > 2      причинних тверджень не буде, зупинись
   CV 1 – 2    межа, потрібні великі ефекти
   CV < 0.7    робочий режим

2  порахуй p/n
   p/n > 0.5   обумовлення не працює, glasso не рятує
   p/n < 0.1   обумовлення працює

3  вибери метод під режим
   є колайдери, важлива точність      ARACNe
   є суміш типів клітин                часткова кореляція
   потрібен напрямок                   тільки LiNGAM, і лише при негаусовому шумі
   мало даних відносно генів           glasso, але виграш малий
   є дані з кількох середовищ          обумовлення + інваріантність

4  зміряй підлогу свого стенда ПЕРШ НІЖ читати числа
```

Крок `4` пропускають найчастіше. Через нього ми самі три місяці читали `1.000` на стовпцях, де підлога дорівнювала `1.000`.
