# 11. Усі ключові числа на одній сторінці

[← назад](00-start-here.md)

Оновлено після виміру підлоги для восьми структур, переходу на звʼязний граф і
подвійного критерію. Числа, що змінились проти попередньої версії, і причини —
у [13-corrections.md](13-corrections.md).

---

## Правило читання

```
AUROC = ймовірність, що метод дав справжній парі вищу оцінку

Але порівнювати треба НЕ з 0.5, а з ПІДЛОГОЮ свого режиму.
Підлога = що отримає метод, який читає лише величину звʼязку.
```

Для колайдера правильна відповідь `0.5`, і `1.000` там означає провал.

---

## Підлога, вісім структур, режим linear

```
структура      пари   m_pos    m_neg    Δ         підлога
confounder     D/S    0.7560   0.7571   −0.00103   0.446
chain          D/S    0.7788   0.7791   −0.00030   0.483
two_hidden     D/S    0.7312   0.7295   +0.00169   0.578
collider       S/N    0.0125   0.0112   +0.00122   0.539
and            S/N    0.0181   0.0110   +0.00708   0.671
ffl            S/R    ← було S/N із підлогою 1.000, стовпець полагоджено
feedback       S/R    ← те саме
or             S/R    ← те саме
feedback_dir   S/R    0.7905   0.7905   −0.00008   0.496
```

### ★ Підлога передбачає маргінальний метод

`80` конфігурацій (`8` структур × `5` режимів × `2` зрівнювання), підлога від `0.000` до `0.870`:

```
|кореляція − підлога|    медіана 0.0029
кореляція проти підлоги  r = 0.971
```

Раніше на `64` клітинках було `0.0035` і `r = 0.943`. Розширення набору залежність не розмило, а **посилило**.

Кореляція сидить **точно** на підлозі скрізь. Отже «неможлива задача виглядає розвʼязаною» — не спостереження, а **обчислювана наперед** величина.

## Класичні методи, лінійний режим, усе видно

```
структура      треба   кор.    MI    частк.  ARACNe   підлога
confounder     високо  0.446  0.421  1.000   1.000     0.446
chain          високо  0.486  0.466  1.000   1.000     0.483
two_hidden     високо  0.577  0.571  1.000   0.571     0.578
collider        0.5    0.539  0.539  1.000   0.462     0.539
and            високо  0.651  1.000  0.650   1.000     0.671
feedback_dir   високо  0.502  0.506  0.508   0.506     0.496
```

Контроль `D` проти `N` — `1.000` у **всіх** клітинках.

## ★ Подвійний критерій

Кожне число проти власної підлоги, обидва зрівнювання, `4` режими:

```
структура    кореляція  взаємна інф.  часткова кор.  ARACNe
confounder      2/10        6/10         10/10       10/10
chain           2/10        4/10         10/10       10/10
two_hidden      3/10        7/10         10/10        7/10
collider       10/10       10/10          2/10       10/10
ffl             2/10        6/10          8/10       10/10
feedback        2/10        6/10         10/10       10/10
and             0/10        8/10          0/10        8/10
or              0/10       10/10         10/10       10/10
РАЗОМ          21/80       57/80         60/80       75/80
```

**ARACNe — єдиний без катастрофічного провалу в жодному стовпці.** Часткова кореляція провалює колайдер (`2/8`) і синергію (`0/8`).

Але у звʼязному графі знак міняється: ARACNe розсипається від незалічених типів клітин (`0.807 → 0.513`), а часткова кореляція ні. **У кожного методу є режим, де він єдиний працює, і режим, де він єдиний ламається.**

---

## ★ Підсумок зі знаком

Сила методу = `|AUROC − підлога|`. Симетрична міра: перевернутий метод інформативний так само, як прямий, треба лише знати знак.

Агрегувати можна **лише зі знаком**: у стовпці колайдера велика сила означає **провал**, у решті — роботу.

```
метод              розрізняє   вигадує   чистий
ARACNe               0.461     0.076     0.385
LiNGAM-асиметрія     0.324     0.047     0.277
взаємна інф.         0.190     0.032     0.159
кореляція            0.006     0.010    -0.004
часткова кор.        0.356     0.515    -0.159
```

**Часткова кореляція вигадує більше, ніж розрізняє.**

Вага `1:3` (один мовчазний стовпець проти трьох розрізнювальних) задана складом стенда, не природою — змінивши склад, можна змінити знак. Що **не** змінюється: провал `0.515` проти виграшу `0.356` в одного й того самого методу.

На наявних бенчмарках це не рахується взагалі — у них немає стовпця, де правильна відповідь «мовчати».

## ★ Звʼязний граф: розгортка `p/n`

`300` генів, змінюється кількість клітин.

```
D проти CONF (треба високо)
p/n     підлога   кореляція   частк. кор.   ARACNe
1.000    0.505     0.504        0.575       0.565
0.500    0.506     0.504        0.700       0.652
0.250    0.510     0.509        0.786       0.749
0.125    0.507     0.507        0.824       0.820
0.062    0.509     0.508        0.851       0.845
```

**Наші `1.000` у сітці ізольованих модулів були артефактом ізольованості.** У мережі максимум `0.85`.

## Колайдер гіршає від більших даних

```
COLL проти N (треба 0.5)
p/n     частк. кор.   ARACNe
1.000     0.543        0.493
0.250     0.677        0.491
0.062     0.888        0.503
```

Часткова кореляція **сходиться до моралізованого графа**. Більше клітин — точніша оцінка неправильної величини. ARACNe тримає `0.49` скрізь.

## Graphical lasso не рятує

```
D проти CONF (150 генів)
p/n     частк. кор.   glasso
1.000     0.548        0.578
0.500     0.620        0.638
0.250     0.711        0.669
0.125     0.807        0.724
0.062     0.832        0.720
```

Перетин: лассо виграє на бідних даних, програє на багатих. При `p/n = 1` дає `0.578` при підлозі `0.504` — тобто **розрідженість не лагодить проблему**.

Побічно: L1 частково гасить колайдерний артефакт (`0.561` проти `0.788`).

## Реплікація під іншою кінетикою

```
D проти CONF     адитивна   Хілла
p/n = 1.000        0.575     0.569
p/n = 0.062        0.851     0.852

COLL проти N     адитивна   Хілла
p/n = 1.000        0.543     0.493
p/n = 0.062        0.888     0.572
```

Крива `p/n` — **не властивість нашого симулятора**. Колайдерний артефакт — навпаки, вп'ятеро слабший під насиченням. **Сила артефакту залежить від адитивності регуляції.**

## ★ Суміш типів клітин

```
A. зсуви типів (конфаундер), усі ребра активні
типів   кореляція   частк. кор.   ARACNe
   1      0.512        0.880        0.807
   3      0.501        0.939        0.564
   8      0.500        0.937        0.513

B. різнорідність активних ребер (природний експеримент), зсуву нема
типів   частк. кор.   ARACNe
   1       0.614        0.671
   3       0.795        0.762
   8       0.868        0.842

C. вилучення типу («деконфаундинг»)
типів   наївний   оракул
   3      0.939     0.811
   8      0.937     0.787
```

`A` — маргінальні методи й ARACNe гинуть, часткова кореляція ні (інші гени слугують проксі типу).
`B` — принцип інваріантності: кілька середовищ **допомагають** обумовленню.
`C` — стандартна практика «регресувати батч геть» коштує `0.15` AUROC.

## ★ Різнорідність рівнів генів, а не розрідженість

При **однаковій** частці нулів:

```
нулі    CV генів 1.29   CV генів 0.10
0.21        0.543
0.24                       0.844
0.47                       0.692
0.70                       0.654
```

Однорідні гени при `70%` нулів кращі за різнорідні при `21%`.

Розгортка:

```
CV генів  нулі   частк. кор.
  1.83    0.35      0.534
  1.00    0.13      0.565
  0.45    0.03      0.799
  0.10    0.01      0.922
```

І при нескінченній глибині (`λ = 3608`) — `0.571`, не `1.000`. Отже справа не в глибині.

## ★ Напрямок ребра

Стовпець `feedback_dir`: двоцикл проти одностороннього ребра рівної сили.

```
метод              AUROC     підлога
кореляція          0.502      0.496
взаємна інф.       0.506
часткова кор.      0.508
ARACNe             0.506
LiNGAM-асиметрія   0.509
```

Усі на підлозі. Форма латентного шуму міняє все:

```
шум        S (двоцикл)   R (односторонній)   відношення
gauss        0.00070        0.00099            1.4
uniform      0.00085        0.01556           18.3
laplace      0.00079        0.01298           16.4
exp          0.00059        0.01500           25.4
```

**Конвеєр лічильників не створює ідентифіковності напрямку** (він симетричний), **але й не руйнує її** — розділення `16`-`25` разів виживає через `exp`, Пуассона й нормалізацію.

**Застереження.** Це вимір на **сирих** значеннях `|R|`, від зрівнювання не залежить. Але сам стовпець вимірний лише при зрівнюванні за кореляцією: під зрівнюванням за взаємною інформацією панель вироджується (підлога `0.000` або `0.852`), і сила LiNGAM над підлогою падає з `0.455` до `0.002`. Під подвійним критерієм стовпець **не проходить**. Причина — механізм, а не вада: див. [18-identifiability.md](18-identifiability.md).

## ★ Міра ідентифіковності

Неможливість зрівняти дві статистики **одночасно** — це і є міра того, скільки інформації в даних, і рахується вона **без жодного методу**:

```
стовпець       шум       залишок    сила LiNGAM
feedback_dir   gauss      0.0006       0.071
feedback_dir   uniform    0.0057       0.433
feedback_dir   laplace    0.0331       0.455
feedback_dir   exp        0.0338       0.521
```

Ранг збігається ідеально. Величина — ні: `uniform` дає малий залишок при великій силі, бо взаємна інформація на квантильних кошиках майже сліпа до **меншої** за гаусову гостроверхості. Додано третю статистику (кореляція квадратів), прогін у роботі.

```
структура      D       S       N      розділення   потрібно
confounder    0.686   0.205   0.197     1.000       високо
chain         0.701   0.211   0.209     1.000       високо
two_hidden    0.671   0.254   0.141     1.000       високо
ffl           0.675   0.342   0.208     1.000       високо
or            0.735   0.433   0.130     1.000       високо
and           0.747   0.441   0.123     0.867       високо
collider      0.727   0.438   0.141     1.000        0.5  ←
feedback      0.670   0.720   0.221     1.000       високо
```

**Колайдер: модель сама вигадала ребро**, якого в даних немає. Той самий механізм, що в часткової кореляції — заповнення пропусків обумовлюється на всьому видимому.

## Вірність методів інтерпретації

```
структура        увага   градієнт   зонд
конфаундер       0.804     0.802    0.787
колайдер         0.657     0.907    0.845
зворотний        0.475     0.641    0.498

надлишковий OR   0.277     0.864    0.886
```

**Увага не відстежує свою власну модель на комбінаторних структурах.**

## Прихований вузол ламає саму модель

```
стовпець                    D      S      відношення   істина
конфаундер, A видно        0.748  0.224     0.164       1.000
конфаундер, A ПРИХОВАНО    0.678  0.670     0.982       0.523
ланцюг, B ПРИХОВАНО        0.767  0.760     0.988       0.447
```

Модель користується несправжньою парою **нарівні** зі справжнім ребром. Винен не метод інтерпретації — винна модель.
