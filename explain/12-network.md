## Навіщо це знадобилось

Вісім структур із файлу `02` — **ізольовані модулі на 2-3 гени**. Панель складається з купи незалежних шматочків:

```python
for _ in range(cfg["n_struct"]):     # 25 НЕЗАЛЕЖНИХ модулів
    fn(p, k, hide)
```

Справжня регуляторна мережа — **один звʼязний граф**. У кожного гена кілька батьків, шляхи перетинаються, між будь-якими двома генами десятки маршрутів.

Різниця не косметична:

```
наш стенд                        справжні дані
155 генів, 5000 клітин           2000 генів, 3000 клітин
p ≪ n                            p ≈ n
обумовлення на 152 чистих генах  обумовлення на 2000 корельованих
```

**`p`** — кількість генів, **`n`** — кількість клітин. Часткова кореляція обертає матрицю `p×p`, оцінену з `n` спостережень. Коли `p` наближається до `n`, оцінка стає ненадійною, і метод розсипається — з причини, якої в ізольованій сітці немає взагалі.

## Як влаштований генератор

### Scale-free граф

```python
def scale_free_dag(n, rng, m=2, alpha=1.0):
    for j in range(1, n):
        w = (outdeg[:j] + 1.0) ** alpha
        idx = rng.choice(j, size=k, replace=False, p=w / w.sum())
```

Вузол `j` бере `m` батьків серед попередніх, з імовірністю **пропорційною їхньому поточному вихідному степеню**. Хто вже має багато дітей, отримує ще — це називають **перевагою приєднання**.

Результат на `200` генах:

```
максимальний вихідний степінь   43
медіанний                        0
топ-5                            15, 34, 38, 42, 43
```

Кілька хабів, більшість вузлів без дітей. Так само влаштовані справжні регуляторні мережі: жменя головних транскрипційних факторів керує сотнями генів.

**Ациклічність** гарантована тим, що батьки завжди мають менший номер.

### Типи пар виводяться з графа

Мотиви не вмонтовуються — вони **виникають самі**, і ми їх вичитуємо:

```python
D     пряме ребро i -> j
CONF  спільний батько, шляху між ними немає
CHAIN шлях довжиною ≥ 2, прямого ребра немає
COLL  спільна дитина, ані шляху, ані спільного батька
N     жодного звʼязку
```

На `300` генах виходить приблизно:

```
D      597 пар
CONF  1727
CHAIN 4168
COLL   173
N    38185
```

## Поламка, яку довелось лагодити

Перша версія давала **нуль сигналу скрізь**, включно з контролем.

Причина: дисперсія росла вниз по графу.

```
дисперсія латентних значень:  мінімум 0.98   максимум 27 939 652
```

Кожен вузол додає внески батьків, кожен батько вже роздутий — виходить експоненційне зростання. Після стандартизації розподіл стає таким важкохвостим, що `99.9%` клітин мають майже однакове значення, і Пуассон зʼїдає весь сигнал.

Фікс — нормувати кожен вузол до одиничної дисперсії одразу після обчислення:

```python
sd = acc.std()
x[:, j] = (acc - acc.mean()) / (sd if sd > 0 else 1.0)
```

Кореляції — величини безрозмірні, тому нормування нічого не спотворює. Після фікса:

```
D      0.2757        CONF  0.1041
CHAIN  0.0666        COLL  0.0553        N  0.0380
```

## Зрівнювання у звʼязному графі

У сітці ізольованих модулів силу можна підігнати коефіцієнтом. Тут не можна — сила пари визначається всім графом одразу.

Тому зрівнюємо **пост-фактум**, `src/eval/strength.py`:

```python
edges = np.unique(np.quantile(pool, np.linspace(0, 1, bins + 1)[1:-1]))
ba, bb = np.searchsorted(edges, sa, "right"), np.searchsorted(edges, sb, "right")
for k in range(len(edges) + 1):
    n = min(len(ka), len(kb))
    ia.append(rng.choice(ka, n, replace=False))
```

Словами: розбиваємо обидва набори пар на `20` кошиків за силою, і з кожного кошика беремо **однакову кількість** пар кожного типу. Результат — дві підвибірки з тотожним розподілом сили.

Це стандартний прийом із епідеміології: щоб порівняти дві групи, підбирають пари з однаковим віком, статтю, тяжкістю.

## Що це означає для наших попередніх чисел

У сітці ізольованих модулів часткова кореляція давала **рівно `1.000`** на конфаундері й ланцюзі.

**Це був артефакт ізольованості.** У звʼязному графі той самий метод дає `0.58` при `p/n = 1` і `0.85` у найкращому режимі.

Тобто наш власний стенд у попередній версії **завищував** можливості обумовлених методів. Тепер це виміряно, а не припущено.

# Результат 2. Колайдер стає гіршим від більших даних

```
COLL проти N (правильна відповідь 0.5)
p/n     часткова кор.   ARACNe
1.000       0.543        0.493
0.500       0.601        0.491
0.250       0.677        0.491
0.125       0.783        0.492
0.062       0.888        0.503
```

Читай напрямок: **чим більше клітин, тим впевненіше часткова кореляція вигадує колайдерне ребро.**

Це не парадокс, а точна відповідність теоремі. Часткова кореляція **сходиться** до моралізованого графа — а в моралізованому графі батьки колайдера зʼєднані. Більше даних означає точнішу оцінку **неправильної** величини.

ARACNe тримає `0.49` на всьому діапазоні — він не обертає матрицю, і моралізація його не зачіпає.

**Практичний наслідок.** «Зберемо більше клітин» не лагодить цю помилку. Вона **посилюється**.

# Результат 3. Суміш типів клітин

`mix_run.py`. Один скелет графа, у кожному типі клітин активна своя підмножина ребер плюс власний зсув базових рівнів. **Тип не спостерігається.**

```python
active = {e: rng.random(k_types) < share for e in edges}
core = [e for e in edges if active[e].all()]      # активні всюди
var  = [e for e in edges if active[e].any() and not active[e].all()]
```

Розвели два механізми факторним планом:

- **`shift`** — зсув базових рівнів, властивий типу. Це конфаундер.
- **`share`** — частка ребер, активних у типі. Це різнорідність механізму.

## A. Зсуви типів вбивають маргінальні методи, обумовлені — ні

`D` проти `CONF`, зсув `0.8`, усі ребра активні скрізь:

```
типів   кореляція   часткова кор.   ARACNe
   1      0.512        0.880         0.807
   3      0.501        0.939         0.564
   8      0.500        0.937         0.513
```

Кореляція падає до рівно `0.500`. **ARACNe валиться разом із нею** (`0.807 → 0.513`) — бо його правило трикутника спирається на маргінальну взаємну інформацію, а та зіпсована.

Часткова кореляція **не помічає проблеми**. Причина: зсув типу — це низькорангова добавка, спільна для всіх генів. Обумовлюючись на двохстах інших генах, метод отримує їх як **проксі** невидимого типу й вилучає його автоматично.

## B. Різнорідність активних ребер ДОПОМАГАЄ обумовленню

Зсув `0`, `60%` ребер активні в кожному типі:

```
типів   часткова кор.   ARACNe
   1        0.614        0.671
   3        0.795        0.762
   8        0.868        0.842
```

Монотонне **зростання**.

Це принцип інваріантності (Peters, Bühlmann, Meinshausen, JRSS-B 2016): дані з **кількох середовищ** роблять причинну структуру ідентифіковною там, де одне середовище не робить. Ребро, активне в одних типах і не активне в інших, дає підпис, якого немає в однорідних даних.

Типи клітин працюють як **природний експеримент**.

Маргінальні методи цим скористатись **не можуть** — кореляція лишається `0.50` на всьому діапазоні.

## C. Вилучення типу погіршує результат

Зсув `0.8`, усі ребра активні:

```
типів   наївний   оракул (тип вилучено)
   3      0.939       0.811
   8      0.937       0.787
```

**Оракул** тут — це коли ми **знаємо** справжню мітку типу й віднімаємо середнє по типу з кожного гена. Найкраща можлива поправка.

І вона **шкодить** на `0.15` AUROC.

Причина: разом із конфаундером вилучається варіація, яка робила ребра ідентифіковними. Зсув типу діяв як зовнішнє збурення — щось на кшталт природної інтервенції — і обумовлений метод її використовував.

**Практичний наслідок, і він проти стандартної практики.** Регресувати геть батч і тип клітини — рутина в аналізі scRNA-seq. На цьому генераторі це коштує `0.15` AUROC для обумовлених методів.

Обережно: це вимір на **нашому** генераторі, з низькоранговим зсувом. Чи переноситься він на справжні батч-ефекти — окреме питання, яке ми не перевіряли.
